    One quick step: add your free API key

    Cloudline gets live weather from OpenWeatherMap, which needs a free API key.

    1. Create a free account at openweathermap.org.
    2. Open API keys in your profile and copy the default key.
    3. Paste it below. It is saved only in this browser.

    A brand-new key can take up to a couple of hours to start working. If you see an “API key” error, wait a while and try again.
